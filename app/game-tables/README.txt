Mario Kart 8 Deluxe (0100152000022000) ships the engine's own pso_manifest.tsv (1,516 pipelines to prepare at a first start: a few minutes).
0100152000022000/pso_learned.txt keeps the 3,568 pipelines learned on a real iPhone on 2026-11-19 (a race needs them: without them a first race freezes for seconds or draws no 3D scene while they compile).
It is a .txt on purpose: the build copies only *.tsv. Appended to a pso_manifest.tsv of that folder it would be shipped again, and a first start would prepare about 4,900 pipelines (4 min 28 s to the first picture of a player on an iPhone 15 Pro, measured).
An export carries the phone's own learned list (games/<id>/pso_user.tsv) beside the pack's seed list; the exported player prepares the libraries of both at its first launch (app/patches/0061).
A library built before a table changed keeps its old one (the pack is topped up only when a table is ABSENT): delete Documents/shaders/<id>/pso_manifest.tsv or rebuild.
