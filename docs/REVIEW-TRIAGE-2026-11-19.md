Input: `iBuilderRust-review-2026-11-19.md` (written by another model, from a static read of a tree that was being edited at the time; its section 7 says so).
Task: challenge every finding against the current code, fix what is really wrong, say plainly what is not.
Method: every claim was re-read in the code as it is now; every claim about a panic, an overflow, a hang or a behaviour got a test written FIRST that fails on the old code (the failure is quoted in
the Evidence column), then the fix. C# cannot be compiled on this machine (and the app must not be built without approval): its fixes are patch files, proven to apply, and marked
**untested on device**. Nothing was built into an IPA, nothing under `iOSBuilder` or `iPorterNX` was written.

that was not taken). "Deferred" = the fix lives in `crates/ibuilder-pipeline/src/{shaders,shaderpack,profile}.rs` (another agent's files while this ran): the exact fix is given at the end, nothing was edited there.
